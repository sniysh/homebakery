# Home Bakery Website

This is a static bakery landing site converted from the provided Elementor export and designed to be deployed on GitHub Pages without any Node modules.

## Pages
- Home
- Our Story
- Our Breads
- Contact

## Run locally
Open `index.html` directly in a browser, or use:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy to GitHub Pages
1. Create a new GitHub repository.
2. Push this folder to the repo.
3. In GitHub, open the repository settings.
4. Go to Pages.
5. Select the branch `main` and the root folder `/`.
6. Save and wait for the site to publish.
